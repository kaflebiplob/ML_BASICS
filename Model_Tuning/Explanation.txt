## Model Tuning

**Model Tuning** is the process of finding the best combination of **hyperparameters** so that the model performs well on **new, unseen data**, not just on the training data.

The main goal of model tuning is to find the **best-performing configuration** of the model.

### Common Problems

During model training, we may face problems such as:

1. **Underfitting** → The model is too simple and performs poorly on both training and unseen data.
2. **Overfitting** → The model performs very well on training data but poorly on unseen data.
3. **Poor Performance** → The model does not perform well enough on unseen data.

To find suitable hyperparameters and evaluate the model more reliably, we use **Cross-Validation**.

### Cross-Validation

**Cross-Validation** is a technique used to evaluate how well a model performs on unseen data.

One common method is **K-Fold Cross-Validation**, where the training data is divided into `K` parts (folds). The model is trained and validated multiple times using different folds.

---

## Hyperparameter Tuning

There are several methods for finding the best hyperparameters:

1. **Manual Search**
2. **Grid Search CV**
3. **Randomized Search CV**

### 1. Manual Search

We manually choose different hyperparameter values, train the model, evaluate its performance, and select the best combination.

### 2. Grid Search CV

**GridSearchCV** tries all possible combinations of the hyperparameters provided in the grid and evaluates each combination using **Cross-Validation**.

For example, for **KNN**:

```python
n_neighbors = [1, 3, 5, 7]
weights = ["uniform", "distance"]
metric = ["manhattan", "euclidean"]
```

GridSearchCV will test combinations such as:

```text
n_neighbors=3, weights=uniform,  metric=manhattan
n_neighbors=3, weights=distance, metric=manhattan
n_neighbors=3, weights=uniform,  metric=euclidean
n_neighbors=3, weights=distance, metric=euclidean
...
```

Since there are:

```text
4 × 2 × 2 = 16
```

possible combinations, GridSearchCV will evaluate all **16 combinations**.

For each combination, **Cross-Validation** is performed and a performance score, such as **accuracy**, is calculated.

Finally, we select the **combination with the best cross-validation score** as the best set of hyperparameters.

### 3. Randomized Search CV

**RandomizedSearchCV** randomly selects combinations of hyperparameters from the given ranges or distributions instead of testing every possible combination.

This can be useful when there are a large number of possible hyperparameter combinations.

---

### Overall Process

```text
Choose Hyperparameters
        ↓
Try Different Combinations
        ↓
Perform Cross-Validation
        ↓
Calculate Performance Score
        ↓
Compare the Scores
        ↓
Select the Best Hyperparameters
        ↓
Train the Final Model
```
