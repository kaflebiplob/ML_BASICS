Pandas
======

Definition
----------

Pandas is an open-source Python library used for data manipulation, data analysis, and data cleaning.

It provides easy-to-use data structures and functions for working with structured data such as tables, CSV files, Excel files, SQL data, and JSON data.

Pandas is widely used in Data Science and Machine Learning for preparing and analyzing datasets before building machine learning models.


Why Use Pandas?
---------------

- To load datasets from different sources.
- To clean and preprocess data.
- To handle missing values.
- To analyze and explore datasets.
- To filter and select data.
- To sort and organize data.
- To group and aggregate data.
- To merge and join multiple datasets.
- To remove duplicate data.
- To perform statistical analysis.
- To prepare data for Machine Learning.


Main Data Structures
--------------------

Pandas mainly provides two important data structures:

1. Series
2. DataFrame


1. Series
---------

A Series is a one-dimensional labeled data structure.

It can be thought of as a single column of data with an index.

Example:

```python
import pandas as pd

data = pd.Series([10, 20, 30, 40])

print(data)
