## Step 1 => Gathering the Text (Getting the Data)

1. Use pre-built public datasets.
2. Web scraping.
3. APIs.
4. Manual collection / Crowdsourcing.
5. Use NLP tools to automatically generate data (Text Augmentation).

## Step 2 => Text Cleaning

1. Convert all text to lowercase.
2. Remove punctuation in ML tasks (e.g., `@#$%^&*`, etc.).
3. Remove numbers (optional, depending on the task).
4. Remove URLs/Links.
5. Remove HTML tags.
6. Remove emojis and special characters.
7. Remove stopwords (e.g., `is`, `the`, `was`, `and`, `in`).
8. Spelling correction (optional).


Step 3=> Feature Extraction/ Vectorization

1 One-hot Encoding
pros 
 i. It is intutive (Can get sentence, words).
 ii. It is easy to implement

cons
 i. Sparsity (Too Big matrix) (to many zeros).
 ii. OOV (Out of Vocabulary)
 iii. Size Difference.
 iv. Semantic meaning.

2. Bag of Words (Bow)
pros
 i. Easy to Implement.
 ii. Fixed Size
 iii. Work with Machine Learning.
 iv. Fast and efficient.

cons
 i. Sparse Matrix.
 ii. Out of Vocabulary
 iii. Semantic Meaning (Better that one-hot encoding)

 N Gram = can be called as Bag of ngrams.
  pros
   i. Semantic meaning (A little bit).


cons
 i. Dimensions increase.
 ii. Out of Vocabulary
