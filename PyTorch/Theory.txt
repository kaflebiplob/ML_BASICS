NEURAL NETWORKS

1. What are Neural Networks?
Neural networks are machine learning models inspired by the human brain that learn patterns from data to make predictions or decisions.

Example: A neural network learns from pictures of cats and dogs and then predicts whether a new picture contains a cat or a dog.

2. GPU (Graphics Processing Unit)
A GPU is a processor designed to perform many calculations at the same time. It is widely used in graphics and machine learning.

3. TPU (Tensor Processing Unit)
A TPU is a special processor designed to perform AI and machine learning calculations faster.

4. What are Tensors?
Tensors are mathematical data structures used to store and represent numbers in different dimensions.

Examples:
- 0D Tensor: A single number (Scalar) - 5
- 1D Tensor: A list of numbers (Vector) - [1, 2, 3]
- 2D Tensor: A table of numbers (Matrix) - [[1, 2], [3, 4]]
- 3D Tensor: A collection of matrices.

- Neural Network: A model that learns patterns from data.
- GPU: A processor that performs many calculations simultaneously.
- TPU: A processor specially designed for AI calculations.
